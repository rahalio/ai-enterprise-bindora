# Bindora — User stories

**Product:** [PRODUCT.md](./PRODUCT.md)


### VP architecture / digital transformation

- As a VP of architecture, I want every channel feature mapped to governed SOE↔SOR APIs, so that we stop growing the hairball.
- As a transformation lead, I want factory-wave progress (governance → frameworks → business services), so that delivery is predictable across the roadmap.

### API product owner (policy / billing / claims)

- As a policy API owner, I want versioned contracts and consumers listed, so that core upgrades do not silently break portals and partners.
- As a billing API owner, I want real-time vs batch designation enforced, so that agent UX is not stuck on overnight cycles.
- As a claims API owner, I want SLA classes and audit logs, so that we meet digital availability and regulatory evidence needs.

### Core SOR owner

- As a policy-admin owner, I want Bindora to prevent SOE apps from writing authoritative state except through my approved APIs, so that single version of truth holds.
- As a core owner, I want canonical field mappings reviewed before publish, so that partner-specific forks do not multiply.

### Digital channel / agent experience lead

- As a portal owner, I want to discover certified APIs for quote-bind-pay-service, so that my team builds on the digital backbone.
- As an agent-experience lead, I want go-live blocked when required APIs are missing or below SLA, so that we do not ship broken self-service.

### Security / data governance / admin

- As a security officer, I want gateway policy and vault binding checked before production publish, so that credentials and exposure are controlled.
- As a data steward, I want glossary and quality rules linked to mutating APIs, so that IFRS and analytics programs inherit trustworthy contracts.
- As an administrator, I want point-to-point exceptions time-boxed with retirement dates, so that debt cannot hide forever.
- As an administrator, I want multi-client API partitions for BPaaS tenants, so that one client never sees another’s policy data.
